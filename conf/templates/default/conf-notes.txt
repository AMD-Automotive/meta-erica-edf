ERICA is built using the AMD Embedded Development Framework - a reference Yocto 
Project distribution that should be used for testing and development purposes only.
It is recommended that you create your own distribution for production use.

The following common machines:
    - vek385-base
    - rave2-baseline
    - amd-cortexa78-mali-common
    - rave2-recovery

Can build the following images:
    - erica-xen-image
    - erica-xen-image-withguest
    - erica-appdev-image
    - edf-ospi
    - rave2-recovery-image
    - rave2-test-image

Examples:    	
    MACHINE=vek385-base bitbake edf-ospi
    MACHINE=amd-cortexa78-mali-common bitbake erica-xen-image
    MACHINE=amd-cortexa78-mali-common bitbake erica-xen-image-withguest
    MACHINE=amd-cortexa78-mali-common bitbake erica-appdev-image
    MACHINE=amd-cortexa78-mali-common bitbake rave2-test-image
